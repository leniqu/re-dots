# re:dots

Мои dotfiles для Hyprland с авто-цветами через Pywal.
Поддерживает Gentoo и Arch Linux.

## Стек
- **WM:** Hyprland (Wayland)
- **Bar:** Waybar
- **Launcher:** Rofi / Wofi
- **Terminal:** Kitty
- **Shell:** Zsh + Oh My Zsh
- **Цвета:** Pywal
- **Визуализатор:** Cava
- **Уведомления:** SwayNC

## Установка
git clone https://github.com/lenique/redots.git
cd redots
./install.sh
